# Gestionale Pizzeria

A custom management system, based on React, implemented in the system with Electron for best compatibility with printers and customer's requestes. Designed specifically to streamline the daily operations of a pizzeria. The main goal of the project is to digitize and optimize the workflow, from taking orders to issuing receipts, improving communication between the dining room, kitchen, and checkout. This also implement a system to comunicate with an application to make order on web or mobile.

## Project Purpose

Managing a pizzeria requires speed, precision, and excellent organization. This project was created to provide a centralized solution that helps restaurateurs to:
* **Reduce errors** when taking orders.
* **Keep track** of business performance through statistics and reporting.
* **Improve the customer experience** with a smoother and more punctual service.

## Main Features

The system is designed to cover all the fundamental needs of a pizzeria:

* **Advanced Order Management:** Quick order entry categorized and customised by customers usual preference. Ability to add specific notes and ingredient variations.
* **Interactive Map:** A visual interface all the order delivery addresses in real-time. Route visulisation and suggestion to make the delibery faster.
* **Dynamic and Customizable Menu:** An administration panel to manage pricing, add new seasonal pizzas, update beverages, and organize menu categories.
* **Dashboard and Statistics:** Track daily and monthly revenues. Analyze best-selling items to optimize purchasing and menu offerings.
* **Bill Management:** Automatic calculation of totals, discount management, bill splitting, and preparation for printing pre-bills and final receipts.
* **Online Menu:** A service that make possibile to customers to order online. (In progress)
